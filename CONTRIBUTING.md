# Contribuir

1. Haz un fork y crea una rama (`git checkout -b mi-cambio`).
2. Compila y prueba: `./gradlew build` (o `mvn clean package`). Java 21.
3. Comentarios en español, nombres de clases y métodos en inglés. Sin TODOs ni métodos vacíos.
4. No uses APIs que no existan en Paper 1.21.1 / BetterModel 2.2.0.
5. Si añades un mensaje nuevo, ponlo en `src/main/resources/messages.yml`.
6. Abre un Pull Request describiendo qué cambia y cómo lo probaste.

Para reportar un fallo usa la plantilla de Issues e incluye versión de Paper, versión del plugin y el log.
